# End's Delight — NeoForge 26.1.2

An unofficial port of [End's Delight](https://github.com/FoggyHillside/End-s-Delight), a culinary addon for Farmer's Delight created by **FoggyHillside** and upstream contributors.

This NeoForge 26.1.2 port is maintained by **[fiddleyowl](https://github.com/fiddleyowl/End-s-Delight)** and is based on the original mod's version 2.6.1.

## Port work

- Updated the build to Java 25 and NeoForge 26.1.2.
- Adapted food, tools, block interactions, loot, stove rendering and synchronization, recipes, and client resources to the newer APIs.
- Preserved the original mod name, namespace, content IDs, translations, and configuration names, with fixes to retain upstream gameplay behavior.

## Requirements

- Minecraft **26.1.2**, NeoForge **26.1.2.126**, and Java **25**.
- [Farmer's Delight 26 Neo Ver **1.3.3-fix8** by BuaichiZY](https://www.curseforge.com/minecraft/mc-mods/farmers-delight-26-neo-ver/files/9236195), installed separately.

Build instructions, testing, implementation notes, and compatibility limits are in [PORTING.md](PORTING.md).
